# 性能与升级边界

#9008 的自动同步会在已有探测周期内增加上游响应字段解析，并在符合条件时写回账号名称和备注。它还增加编辑器预览请求。本站没有启用这条路径，因此本批没有增加请求内数据库访问、后台 worker、计费队列或缓存写入。当前探测 runner 仍保持每周期最多 20 个账号、4 个并发槽位。

#9045 的本地适配只在已有非流式错误路径增加两个有界 `gjson` 字段读取，并复用已有错误信封构造。它不增加外部 I/O、锁、goroutine 或请求体复制。正常成功请求和流式热路径不经过这段逻辑。

#9052 的上游实现会为每条覆写模板扫描变量，并把身份纳入 OpenAI WebSocket 连接池的复用键。用户数增加时可能增加分桶数量、握手次数和排队压力。由于当前项目的 context、错误记录和连接 owner 不同，未将这条性能影响带入默认路径。

升级只改变 gorilla/websocket 依赖和非流式 `response.error` 字段提取，没有数据库 migration、Redis key、队列格式或持久化字段变化。旧二进制可以继续读取现有账号 Extra 和错误记录。回退到旧二进制会恢复原来的通用错误映射，不会产生数据回滚动作。
