# 媒体上游协议

多模态分组从所选账号的 `credentials.media_protocol` 选择出站协议。未设置或设置为 `relay` 时使用兼容中转，`ark` 使用火山方舟原生接口。入口、账号权限、凭据、限流、用量和结算由网关负责。新增原生协议在本包实现 `Driver` 的操作路径、请求转换和视频任务解码，并在 `Select` 登记。

方舟支持文生图、带参考图的编辑、文生视频和单首帧图生视频。图片生成和编辑都提交到方舟图片接口，支持流式上游的模型可以提前发送事件。客户端可选择 JSON 或 SSE 获取图片和视频任务回执。视频提交、查询和取片使用方舟任务接口。上游返回的签名取片地址只在通过归属与结算检查后由内容端点重定向交付。账号配置、保活间隔和升级顺序见[媒体工坊文档](../../../../docs/CUSTOM_MODELS_AND_MEDIA.md)。
