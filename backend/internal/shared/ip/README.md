# ip

可信代理下的客户端 IP 解析与 API Key IP 白名单/黑名单校验。文件索引：`ip.go`、`resolver.go`、`prefix_bloom.go` 及测试。

`CompileIPRules` 将 IP/CIDR 编译为不可变规则，随 API Key 鉴权快照在进程内复用。至少 64 条有效规则、且平均每种地址族/前缀长度至少 16 条规则时，额外建立有容量上限的布隆过滤器。匹配先检查前四条规则，再按请求 IP 的地址族和已配置前缀长度查询网络地址；确定不存在时跳过剩余遍历，可能存在时继续精确 `Prefix.Contains`。误判只增加精确比较，不改变允许/拒绝结果；小列表或前缀长度过于分散时使用直接遍历。

过滤器随整份规则快照重建，不在请求路径写入，无新增数据库或 Redis 操作。IPv4、IPv6、IPv4-mapped 地址沿用现有归一化；黑名单优先、非法白名单拒绝、空白名单放行的语义保持一致。`ip_benchmark_test.go` 保留同输入对比夹具，`prefix_bloom_test.go` 覆盖网络长度、强制误判、并发读取及兼容性。
