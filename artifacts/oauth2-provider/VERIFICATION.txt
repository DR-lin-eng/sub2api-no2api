Changed branch/field
--------------------
The changed authorization branch is the new OAuth2 authorization-code provider:
backend/internal/application/service/oauth2_provider.go validates an administrator-managed
oauth2_provider_config record plus oauth2_provider_client.<client_id> records, requires exact
redirect URI matching and PKCE S256, atomically consumes authorization codes from Redis, and
revalidates the provider, client, scopes, user status, and TokenVersion on every userinfo call.
The embedded frontend branch in backend/internal/transport/webassets/embed_on.go now bypasses
SPA handling for discovery, token, userinfo, and revoke while preserving /oauth/authorize as
the authenticated Vue consent page. OAuth2 trust writes additionally pass AdminSessionOnly, so
Admin API keys and delegated staff cannot modify them. OAuth2 tokens remain invalid as site
JWTs and gateway keys.
