**升级和回退。** 本批使用现有数据库结构、Redis 键、消息队列和本项目版本编号。首次读取可以接收旧版包含完整分组对象的账号缓存；候选写入的精简对象保留分组 ID、优先级和创建时间。OpenAI 刷新令牌一经上游轮换，旧值便可能失效。滚动时先升级负责刷新和请求内强制刷新的节点，再恢复跨版本流量。回退可复用数据库中最新凭据，恢复旧凭据备份可能使账号需要重新授权。

通常的 JSON 和 SSE 调用保持原有响应协议。请求出现重复控制字段会返回客户端错误；首次和后续 WS 帧使用同一校验。工具 schema 的自定义属性保留大小写区别。混合部署时，涉及重复字段的客户端应先去重。显式选择 Exa 的管理配置应在全部处理搜索请求的节点升级后启用，回退前可切回原提供商。TypeSafe 的账号级模型映射现在会实际用于转发，部署前应检查存量映射的目标名称。Claude Code 压缩请求在已开启 TTL 注入时使用 5m，可能改变后续新请求的上游缓存写入成本。历史结算记录沿用原金额。
