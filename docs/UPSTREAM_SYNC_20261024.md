## 兼容与性能边界

新增 `UpstreamFailoverError.SameAccountRetryDelay` 仅为进程内的可选字段，无数据库迁移或外部 API
字段变化。等待提示以现有指数退避为下限，单次不超过 8 秒；请求级总预算、账号重试次数、
取消、粘性会话、账号失败归因及已输出后不可重放的边界保持原有路径。

数值提示支持小数秒和毫秒；HTTP 日期仅用于秒制 Retry-After。有限大数先限幅再转换，拒绝
NaN、无穷、溢出、负数和失效日期。只有容量错误解析提示，成功流的逐事件判定没有新增解析、
数据库访问、队列、缓存或 goroutine。提示缺失时沿用旧退避。

升级可逐实例替换；混合版本中旧实例仍使用原退避，新实例采用等待提示，不涉及存储格式切换。
回退恢复旧等待行为，已有身份、Key、订阅与余额仍由原持久化链路管理。

Docker 验证、固定输入微基准、同库升级/回退、源码重建与发布证据统一存放在
[本轮诊断目录](../diagnostics/upstream-sync-20261024/)。基准只代表固定函数夹具，不能外推生产吞吐。
