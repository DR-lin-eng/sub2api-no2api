## 性能和边界

Gemini 图片 part 单次遍历，普通文字不连续查询四种图片键；不请求输出 URI，不增加后台任务或持久状态。
Claude 指纹仅扫描需要的文本前缀；OpenCode 模型读取位于目标资格检查之后，避免无关大请求新增全体扫描。
模型广场对 repository 返回的未编译分组只构建一次现有价格索引，复用到各模型；不按模型增加数据库查询，也不修改渠道缓存价格。
上传沿用已有请求体、并发及待处理字节门禁；50 MiB 单文件会使用比原 20 MiB 更高的内存，应保持总请求体上限。
未引入上游新增上传日志切片分配。固定 Docker 函数夹具性能见诊断目录，不能外推生产吞吐。

## 平滑升级

无新增 SQL 迁移、Ent/Wire 生成、配置字段、数据库格式、缓存版本或凭据。身份、持久 Key、订阅和历史用量
沿用当前存储；回退不执行 Down SQL。分页合法普通输入维持原行为，异常大页返回空页或入口既有 400 语义。
畸形工具调用原先的空成功变为明确失败；正常文本、正常工具和流式转换继续走原路径。

DeepSeek Pro **默认未来费用会提高到 Pro 价卡**，历史账单不重算；自定义单价不被覆盖，缓存命中修复则会
正确区分输入与缓存用量。滚动期间新旧节点的默认 Pro 费用、fileData 计图和上传能力不同，应先排空旧节点，
或使用既有显式分组价稳定 Pro 单价，并等全部节点升级后开放大文件请求。回退会恢复旧二进制的这些行为，
不会撤销已落库账务。不能把无迁移解释为混合版本行为完全相同。
