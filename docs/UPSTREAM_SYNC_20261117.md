## 价格与性能

独立读取的 SiliconFlow 国际站公开价卡见[价格来源记录](../diagnostics/upstream-sync-20261117/PRICING_SOURCE.json)。
本批采用的 USD / 1M 输入 token 价格：Embedding 8B/4B/0.6B 为 $0.04/$0.02/$0.01，
Reranker 8B/0.6B 为 $0.04/$0.01。Reranker-4B 的公开页面未提供可核实美元价，
需要运营方设置明确的分组/渠道价；不按其他型号的隐含汇率猜测。

价卡仅在原价格查询失败后兜底，分组、渠道和动态价格优先级保持原契约。
匹配读取已小写化的模型 ID，接受裸名、`Qwen/`、`siliconflow/` 前缀及 `0-6b` 拼法；
未知尺寸、VL 型号、前后附加字符和未核实版本不会获得新增兜底价。
启动时初始化 5 个固定条目，查询使用字符串前缀与 switch；不新增外部 I/O、逐请求数据库查询、
Redis 操作、timer 或 worker。原计费队列、幂等结算、调度和槽位释放继续由现有 owner 持有。
性能采样与验证命令见[证据目录](../diagnostics/upstream-sync-20261117/README.md)，局部采样不代表生产吞吐。

## 平滑升级与回退

本批不新增或修改数据库迁移、Ent/Wire 生成代码、鉴权快照版本、Redis key 或持久队列格式。
历史账单不重算，HTTP JSON/SSE/WS 协议保持原有实现。

依赖内置兜底的这 5 个型号，新节点会从缺价处理切换到已核实输入价；旧节点仍有旧的缺价行为。
滚动升级前先在分组或渠道保存明确价格，确保新旧节点及异步结算 worker 使用相同价格。
全部处理该流量的节点升级后再考虑删除显式覆盖。回退时继续保留覆盖，或暂停这些型号的流量；
不能将“二进制可以共用数据库”误认为新旧缺省收费必然相同。

同库验证使用临时 PostgreSQL/Redis 和假上游，按基线→候选→回退→恢复核对持久身份、API Key、
订阅、迁移记录、历史账单摘要和余额等式。真实上游权限与生产吞吐不在假上游验证范围内。
本轮实际结果和精确 SHA 的 CI 状态见[验证记录](../diagnostics/upstream-sync-20261117/VERIFICATION.md)。
