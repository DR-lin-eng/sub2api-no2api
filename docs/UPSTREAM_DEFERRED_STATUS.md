## 本轮实现

- 订阅退款兑换在原事务内锁定并重读订阅；日历扣减后仍剩数小时的订阅继续有效。代理到期 UPDATE 复核有效期、状态和回退配置；禁用的备用节点不可被选择；恢复原出口时清除旧出口的探测快照。
- OpenAI 流错误接受 `status` / `status_code` 两种字段，保持本站错误映射和安全重放约束。有效 access token 或旧额度快照不能自动清除 refresh-token 错误。非法 Codex UA 回到独立解析的同步版本，有效 Desktop 双版本保留；turn metadata 输出 ASCII JSON，Unicode 和大整数的值不变。
- Coding Plan 配额耗尽 403 不再永久禁用账号；仅使用已耗尽窗口的有效未来重置点。Gemini 补 RPC RetryInfo，保留真实日配额和 Vertex 共享容量策略。Antigravity 三种入口统一选择裸 Gemini 思考变体，显式映射和自映射优先；go/python GenAI SDK 不再接收其无法解析的注释心跳。Grok 冷却期间仍可诊断额度，模型调度状态不由诊断恢复。
- 工具 schema 补 `required:null`、Messages `input_schema`、Gemini 元组数组和 Anthropic 对象根联合。清洗只沿 schema 边遍历，不改默认值/常量或同名用户属性。根联合改为收集分支后一次编码，最多 512 分支和 16 层，超限保留原 schema。对象根联合不能保留所有跨属性的分支关联，沿用上游工具兼容的属性合并目的；不作为本站参数授权或执行校验。
- 前端修复用户/账号/监控切换后的旧响应覆盖、公告跨会话返回、设置失败重试、未加载分组即保存、IME 提前搜索/提交标签、上传读取竞态、卸载后启动 TOTP timer、日期跨午夜和取消编辑、RPM/倍率校验、科学计数 token 边界、回调斜杠及日历到期标签。

## 性能审查

DeepSeek 原实现对每条 assistant 消息在完整请求上执行一次 JSON set，历史越长复制越多。候选只改目标消息对象，随后一次拼接请求；非目标请求和已有明文 reasoning 保留。

| 固定 Docker linux/arm64 输入 | 主线中位耗时 | 候选中位耗时 | 主线 B/op | 候选 B/op |
| --- | --- | --- | --- | --- |
| 100 条 assistant 历史 | 448112 ns | 36778 ns | 1058712 | 51288 |
| 1000 条 assistant 历史 | 37215433 ns | 357461 ns | 88746865 | 501400 |

相同 Go 1.26.11、2 CPU、输入和 benchmark，各运行三次。原始样本见 [performance 记录](../diagnostics/upstream-deferred-20261115/records/performance.json)。这些数字不代表生产吞吐。schema、元数据与分组校验不新增外部 I/O、逐请求数据库查询、worker 或 timer；前端竞态保护是常数时间的请求版本比较。

未采用的性能方案也记录了原因：余额预占不能叠加每流续期和 Lua 全集合求和；调度 memo 不能共享可变嵌套对象、无容量上限或忽略旧写入节点；上游按 hash 无条件释放 session 不能清除另一并行请求的租约。新的 token TTL、免费 Fast、资源授权和显式 Gemini cache 需要独立契约，不能只移植默认价或迁移编号。

## 平滑升级与回退

本轮不新增数据库 migration、Ent/Wire 生成结果、持久账单字段、Redis key 或序列化队列格式；两个二进制共用原数据库和缓存。旧账号显式模型映射继续优先，历史费用不重算。

先让处理负数订阅兑换和代理到期任务的节点升级，再恢复这些操作的并发执行。混合版本中的旧兑换节点和旧扫描 worker 仍有原竞态，不能用新节点的单元测试宣称整组已经具备保证。需要回退时，先暂停这些并发写入或把相应操作路由到仍保留修复的节点；回退二进制不执行 Down SQL。

裸 Gemini 模型在未显式映射时新增思考变体解析。对需要跨版本保持完全相同目标的分组，可先保存明确的目标变体映射，再滚动替换网关节点。上游 OAuth、真实模型吞吐与生产数据不在本地假上游夹具的验证范围内。
