# Public account quality

`presentation/pages/AccountQualitySharePage.vue` is the anonymous, aggregate quality dashboard at `/monitor/quality/public`. `data/datasources/accountQualityPublicDatasource.ts` owns the read-only `/account-quality-share` contract. It follows the manxue.ai-style flow of summary cards, a clickable 24-hour timeline, and an evidence gallery. Each record can show the provider conversation/response ID, bounded final answer text for both stages, reasoning tokens, status, and a WebP or embedded SVG preview. The page renders answers as escaped text; credentials and account IDs are never exposed.
